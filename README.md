## About

A single-page portfolio site with a space theme — planets, orbits, and a dark, immersive backdrop. Built to load fast with zero dependencies. No framework, no build step: just `index.html`.

<br>

## Design

- **Theme:** solar system / planets — orbiting elements used to represent projects and sections
- **Palette:** dark space background with accent highlights
- **Layout:** immersive, visual-first presentation over dense text

<br>

## What's Inside

Showcases three shipped products:

| Project | Description |
|---|---|
| **EntryHive** | University entry test prep platform for Pakistani students |
| **Calobit** | AI-powered calorie and nutrition tracker |
| **SpendSense** | Automatic expense tracker for Android |
